# SSH-MCP 接入评估与落地实施方案

## 是什么

SSH-MCP（SSH Model Context Protocol）是**本地中控层 SSH 代理调度工具**，本质是原生 SSH 协议的上层标准化管理代理，不改变底层 SSH 通信协议。

## 核心价值

| 痛点（现有 ssh -i 方案）| SSH-MCP 解决 |
|---|---|
| 私钥硬编码，高泄露风险 | 凭据统一托管，AI 全程不接触密钥 |
| AI 误操作无防护 | 命令白名单 + 环境隔离，双层拦截 |
| 短连接易断连 | 长连接会话，流程连贯稳定 |
| 无审计日志 | 全链路结构化审计，自然语言指令→执行→结果全程可溯源 |

## 关键部署边界

**仅需在本地/中控机部署，远端集群零要求：**
- 无需安装任何代理、守护进程
- 无需修改 sshd 配置
- 无需新增端口、白规则
- 远端完全无感知，零侵入

## 三阶段落地路径

```
阶段1（短期）→ 沿用 ssh -i/scp -i
     ↓ 环境增多、团队扩展
阶段2（推荐）→ 本地部署 MCP，新增环境走 MCP，存量保留原方案
     ↓ 需合规审计、团队共用
阶段3（长期）→ 全面替换，统一 MCP 调度
```

## 适用场景

- ✅ AI 自然语言驱动多环境集群自动化发布（你的场景）
- ✅ 多套环境（测试/预发/生产）、多台服务器批量操作
- ✅ 需要安全防护、操作审计、权限管控
- ❌ 纯人工手动发布场景（不需要）

## 平滑改造 5 步

1. 本地部署 SSH-MCP，完成密钥/环境统一配置
2. 上层 Skill 逻辑完全不变
3. 底层执行层兼容替换（统一调度入口）
4. 存量逐步迁移 ssh -i → MCP
5. 启用审计与权限管控
