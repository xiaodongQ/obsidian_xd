# LLM Wiki / Obsidian-Wiki / GBrain 深度解析

## 核心主题

本文从**知识工程（Knowledge Engineering）**角度，深度解析三个系统在 Agent 时代如何实现知识的"自组织"与"自进化"：

- **LLM Wiki** — 基于大模型的知识库自组织模式
- **Obsidian-Wiki** — 本地双向链接知识库
- **GBrain** — 阿里知识大脑系统

## 核心观点

### 1. Agent 自进化的两条路径

| 路径 | 方式 | 门槛 |
|------|------|------|
| RL 训练 | 强化学习深度训练 | 高（面向 AI 研究/算法同学） |
| **Skill 机制** | 通过 Skill 自动沉淀实现自进化 | 低，更具普适性 |

### 2. 知识库的"自进化"目标

当前 Skill 自动更新的局限：触发时机和可控性相对较低。

理想状态：知识库能够**自动梳理、自动组织、自动更新、自动进化**，推动 Agent 不断"自进化"。

### 3. 从"知识堆积"到"结构化记忆"

Agent 需要的不只是知识的存储，更需要：
- 知识的**自动结构化**
- 知识的**主动关联**（双向链接）
- 知识的**动态更新**

## 与知识库的关系

本文与用户知识库（`obsidian_xd`）高度相关：
- 用户正在实践的 **LLM Wiki 模式**正是文章讨论的核心范式
- **Obsidian双向链接**是本地知识自组织的关键技术
- **Skill 自动沉淀机制**是 Agent 自进化的轻量路径
