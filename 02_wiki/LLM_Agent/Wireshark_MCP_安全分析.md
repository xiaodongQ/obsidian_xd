# AI+安全｜用 Trae + Wireshark MCP 分析网络流量

## 核心内容

使用 **Trae IDE** + **Wireshark MCP** 让 AI 直接"看懂"网络流量，通过自然语言交互完成 2025 CISCN 网络安全竞赛流量分析题。

## 关键技术点

### MCP 协议应用
- **Wireshark MCP** — 将 Wireshark 的流量分析能力通过 MCP 协议暴露给 AI
- AI 无需理解 pcap 格式细节，通过自然语言指令即可操控 Wireshark
- MCP 协议打通了 AI 与专业安全工具的连接

### AI + 安全工具链
- **Trae** — AI IDE，支持 MCP 扩展
- **Wireshark** — 网络协议分析器
- **CISCN 2025** — 全国大学生信息安全竞赛，流量分析是经典题型

## 核心流程

```
用户自然语言指令 → Trae AI → Wireshark MCP → Wireshark 执行 → 流量分析结果回传
```

## 意义

- 展示了 **MCP 协议在垂直领域的深度应用**（安全分析）
- AI 借助工具可以处理专业领域的结构化数据（pcap 流量）
- 降低了安全分析的门槛——不需精通 Wireshark 也能做流量分析
