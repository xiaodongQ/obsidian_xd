# LLM 智能体外部化综述

## 概述

> arXiv: 2604.08224 | 上海交通大学、中山大学、卡内基梅隆大学、OPPO

本文通过**外部化（Externalization）**的视角统一审视 LLM 智能体架构演化。核心论点：可靠智能体并非仅来自更大模型，而是来自系统性地重构任务需求，使内部能力和外部基础设施共同覆盖所需能力。

借鉴 Norman 的认知人造物理论：外部辅助工具不仅放大内部能力，还会**转变任务本身**——将困难的生成问题转化为更易处理的识别/组合/结构化交互问题。

## 核心框架：四种外部化

| 外部化形式 | 外部化的负担 | 表征转换 | 解决的 Mismatch |
|-----------|-------------|---------|----------------|
| **记忆** | 状态（跨时间） | 回忆 → 识别 | 连续性问题 |
| **技能** | 程序化专长 | 生成 → 组合 | 方差问题 |
| **协议** | 交互结构 | 临时 → 结构化 | 协调问题 |
| **驾驭工程** | 运行时协调 | — | 统一以上三者 |

驾驭工程不是第四种外部化，而是前三种外部化形式运行并交互的运行时环境。

## 从权重到上下文到驾驭系统

三层层叠演化（非互斥）：

### 权重层

能力 = 模型参数。优势：快速推理、部署紧凑、跨任务泛化。局限：难以选择性更新/组合/治理。

### 上下文层

能力 = 输入设计。提示工程、RAG、思维链等。转变：回忆问题 → 识别问题。局限：上下文窗口有限、"迷失在中间"、状态短暂。

### 驾驭系统层

能力 = 持久基础设施。记忆存储、工具注册、协议定义、沙箱、子智能体编排等。工程注意力从"告诉模型什么"转向"让模型在什么环境中运行"。

## 记忆：状态外部化

### 四个维度

| 维度 | 内容 | 特点 |
|------|------|------|
| 工作上下文 | 当前任务的实时中间状态 | 变化迅速，过时即失去价值 |
| 情景经验 | 先前运行的决策、失败、反思 | 作为具体先例，避免重复错误 |
| 语义知识 | 领域事实、项目约定、世界知识 | 超越单情景的抽象内容 |
| 个性化记忆 | 用户偏好、习惯、约束 | 跨会话适配，独立隐私规则 |

### 四代架构

1. **单体上下文**：所有历史保留在提示中。简单但容量差、状态短暂
2. **上下文+检索存储**：近期在上下文，长时序外部检索。记忆质量=检索质量
3. **分层记忆与编排**：热/冷存储分离（类OS），或按功能/内容类型组织。引入提取、整合、遗忘操作
4. **自适应记忆系统**：模块动态演化（MemEvolve），或基于反馈优化检索策略（MemRL）

> 核心转变：从存储转向控制。记忆不再是提示的被动附属，而是驾驭系统控制面的一部分。

## 技能：专长外部化

### 三个组成部分

| 组成 | 作用 |
|------|------|
| **操作程序** | 任务骨架：步骤、依赖、停止条件 |
| **决策启发式** | 分支点行为：默认选择、升级规则、偏好排序 |
| **规范约束** | 可接受的边界：合规、安全、操作规则 |

### 三阶段演化

1. **原子执行基元**：函数调用、工具使用。基本单元是动作
2. **大规模基元选择**：从大量工具中检索选择。基本单元仍是工具
3. **打包的专长**：能力单元 = 可复用的程序化知识，而非孤立调用

## 协议：交互外部化

将临时提示协调转化为结构化的交互机制。定义 Agent 与工具、其他 Agent、用户间的标准化契约，涵盖能力发现、任务委托与身份验证。

## 驾驭工程：统一外部化

整合 Runtime、Sandbox、观测机制，负责状态管理、失败恢复、权限控制。从辅助组件演化为定义智能体能力边界的核心基础设施。

## 关键洞察

1. **认知人造物的力量在于表征转换** — 不是增加信息，而是重新组织认知任务
2. **检索质量 > 存储容量** — "我们保存了多少"不重要，"我们是否让当前决策变得可读"才重要
3. **外部化不是替换模型** — 而是在模型周围构建更大的认知系统
4. **参数化 vs 外部化存在权衡** — 不同任务的最优分配不同
